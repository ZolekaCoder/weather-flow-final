# weatherflow

Honours research project comparing a lightweight spatio-temporal graph neural network (STLGRU) against a baseline (CLCRN or AGCRN) on South African weather data.

## Folder map

- `data/raw/` — SAWS / ERA5 files exactly as downloaded, never edited
- `data/processed/` — cleaned tensors generated by code
- `src/data_prep/` — loading, imputation, splits, adjacency construction
- `src/models/` — STLGRU and baseline model implementations
- `src/training/` — train loop, checkpointing
- `src/evaluation/` — metrics, comparison tables
- `analysis/` — Lyapunov / VPT / Pareto analysis, kept separate from src on purpose
- `notebooks/` — exploration only, nothing here gets imported by src
- `configs/` — experiment settings
- `runs/` — checkpoints + per-run result.json (gitignored)
- `results/` — final tables + figures for the paper (gitignored)
- `tests/` — sanity tests, added as src fills in
- `ideation.md` — running decision log

## How this repo grows

`data_prep` first → `models` → `training` → `evaluation` → `analysis`.
